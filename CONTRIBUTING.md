# Contribution Guidelines

Thanks for contributing to Awesome Terracotta!

## Suggest a Project

Edit [`README.md`](README.md), add the project under the most appropriate category, and open a pull request:

```markdown
- [Project Name](https://github.com/owner/repository) - A short description of the project.
```

A project should:

* be directly related to Terracotta or DiamondFire development;
* be publicly accessible;
* use Terracotta in a meaningful way, if submitted as a Terracotta project;
* have a clear README or other documentation explaining what it does;
* fit an existing category where possible.

Keep descriptions short, factual, and focused on what makes the project useful or interesting.

Please check the existing list before submitting to avoid duplicates. Self-promotion is welcome as long as the project meets the same requirements as any other submission.

Use one pull request per project.

## Suggest a Resource

Resources such as documentation, tutorials, examples, tools, or other useful Terracotta/DiamondFire references are also welcome.

Add the resource under the most appropriate section:

```markdown
- [Resource Name](https://example.com/) - A short description of the resource.
```

Use the project's official or canonical link when possible, and make sure the resource is still available and relevant.

## Adding a Category

If your submission doesn't fit any existing category, you may suggest a new one.

Only add a category when there's a reasonable distinction from the existing sections. Avoid creating a new category for a single highly specific project when an existing one works just as well.

## Pull Requests

Before opening a pull request:

* make sure the link works;
* check that the project or resource isn't already listed;
* place it under the most appropriate category;
* keep the description concise and neutral;
* follow the existing Markdown formatting;
* avoid unrelated changes.

A pull request should generally add or change one project or resource at a time.

## Removing or Updating Entries

Pull requests that update broken links, outdated descriptions, renamed projects, or other incorrect information are welcome.

Projects may be removed if they are no longer publicly available, no longer related to Terracotta/DiamondFire, or otherwise no longer fit the list.
