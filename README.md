# Awesome Terracotta [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of Terracotta libraries, tools, resources, and open-source DiamondFire projects.

[Terracotta](https://github.com/Owlfroggy/terracotta) is a text-to-block-code programming language for [DiamondFire](https://mcdiamondfire.com/), designed to make building complex DiamondFire projects easier without giving up access to the platform's features.
